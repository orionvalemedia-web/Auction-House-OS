# Contributing

Code contributions are not accepted.

This repository is documentation only. There is no source code here to contribute to. Pull
requests containing code will be closed without review.

The software itself is proprietary and developed privately. Its source is not published here or
anywhere else. See [LICENSING.md](LICENSING.md).

---

## Why

This is not an open-source project and is not heading that way. Setting it up as if it were open
to contribution would misrepresent what it is, and taking outside code into a proprietary codebase
would create ownership questions in an asset whose clean provenance is one of the things it gets
judged on.

## What is welcome

**Documentation corrections.** If something here is wrong, inconsistent, or contradicted by
another document in this repository, that is worth reporting. An issue is enough, no pull request
needed.

**Questions.** If something is unclear or under-explained, say so.

**Pushback on the claims.** Everything here is written so it can be checked. If you think a claim
does not hold, that is a fair thing to raise and it is welcome.

## What will not happen

- Pull requests containing code, in any language, for any reason
- Publishing the source, in whole or in part
- Relicensing as open source
- Feature requests
